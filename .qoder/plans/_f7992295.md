5. SDK 客户端已暴露 get_task/cancel_task/list_tasks/subscribe，只做薄封装

## Task 2: 执行器重构 [server/agent_executor.py](file:///Users/shixiangweii/PycharmProjects/2026_qoder_proj/a2a_demo/server/agent_executor.py)
改用 TaskUpdater：
```python
updater = TaskUpdater(event_queue, context.task_id, context.context_id)
await updater.submit()         # SUBMITTED
await updater.start_work(...)  # WORKING
# 按 skill_id 分支：
# - requires_input → INPUT_REQUIRED
# - reject         → REJECTED
# - cancel         → CANCELED
# - complete(add_artifact)
```
分支规则：
- 无 text 且无 data metadata → `requires_input("请提供待翻译文本，或指定 skill_id")`
- text 检测为纯 ASCII 英文 → `reject("本 Agent 仅支持中译英，不接受英文输入")`
- metadata.skill_id == "slow_translate" 时调用 slow_translate，监听 `cancel()` 事件（结合 Task 3）
- metadata.skill_id == "detect_language" → 用 DataPart 返回 `Part(data=Value(struct_value=...))`
- metadata.skill_id == "translate_file" → 读 `Part(raw=..., filename=..., media_type="text/plain")`，翻译后产出同样 media_type 的 Artifact Part
- 默认 → 翻译（保留原流程）

保留原手写 `TaskStatusUpdateEvent` 写法在一个注释块里作为教学对照。
